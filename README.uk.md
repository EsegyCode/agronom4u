# Agronom4u (Українська)

Аграрний портал українською мовою для польових і городніх культур, калькуляторів, сівозміни та блогу.

Джерело даних: `src/data/`. Сайт статичний, стек: Astro 5.1. Опублікований URL: `https://agronom4u.com`.

## Запуск

```sh
npm install
npm run dev
npm run build
npm run preview
```

Вихід збірки: `dist/`. Змінні середовища не використовуються.

## Основні можливості

- Польові культури: соя, пшениця, кукурудза, соняшник; по 13 тем.
- 18 городніх культур.
- 3 калькулятори: схожість, урожайність, економіка 1 га.
- Планувальник сівозміни.
- FAQ на основі нотаток агронома.
- `/llms.txt`, sitemap, robots, OG-зображення.
