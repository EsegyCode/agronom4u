# Features (Agronom4u)

Purpose: complete list of user-facing and technical features present in the repository.

## Content and navigation

- Field crop guides for soy, wheat, corn and sunflower.
- Each field crop page has 13 ordered cultivation topics (`FIELD_TOPICS` in `src/data/fieldCrops.ts`).
- Garden crop index and pages for 18 garden crops (`src/data/gardenCrops.ts`).
- Blog index and per-post pages (`src/data/blog.ts`, `src/pages/blog/posts/[slug].astro`).
- FAQ page backed by `FAQ_ITEMS` in `src/data/faq.ts`.
- Crop rotation planner at `src/pages/crop-rotation/index.astro`.
- Manual gallery page in `src/pages/gallery/index.astro`.
- Mobile app landing page in `src/pages/app/index.astro`.

## Calculators

- Germination and sowing norm calculator (`src/pages/calculators/germination.astro`).
- Yield forecast calculator (`src/pages/calculators/yield.astro`).
- Per-hectare economics calculator (`src/pages/calculators/economics.astro`).

## AI and SEO readiness

- AI-facing plain text generated at `/llms.txt` by `src/pages/llms.txt.ts`.
- XML sitemap generated by `@astrojs/sitemap` in `astro.config.mjs`.
- Robots rules and AI crawler allow rules in `public/robots.txt`.
- Canonical URL, Open Graph and Twitter card metadata in `src/layouts/BaseLayout.astro`.
- Organization JSON-LD schema on every page through `BaseLayout.astro`.

## Media

- 12 Open Graph card PNGs under `public/og/`.
- OG assets generated by `scripts/generate-og.mjs` using Sharp.
- Brand assets under `public/`: `logo.svg`, `logo-dark.svg`, `favicon.svg`.

## Technical features

- Single shared layout and navigation in `src/components/Header.astro` and `Footer.astro`.
- Central site configuration and navigation in `src/data/site.ts`.
- Static page output through Astro with `build.format: 'preserve'` in `astro.config.mjs`.
- Post-build link check via `scripts/verify-dist.mjs`.

## Configuration touchpoints

- Site URL, sitemap settings and build format: `astro.config.mjs`.
- OG badge/title/subtitle text and card list: `scripts/generate-og.mjs`.
- Crop, topic, blog and FAQ records: files in `src/data/`.
