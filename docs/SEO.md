# SEO and AI Readiness (Agronom4u)

Purpose: document search and AI-facing mechanisms implemented in the codebase.

## Meta tags

`src/layouts/BaseLayout.astro` emits title, description, canonical link, robots for no-index pages, Open Graph and Twitter card tags.

## Structured data

- Organization schema is generated in `BaseLayout.astro` and added to every page.
- Additional page schema can be supplied through the `schema` prop.

## Sitemap and robots

- `@astrojs/sitemap` generates sitemap files with priority `0.7` and weekly change frequency.
- `public/robots.txt` allows all crawlers, GPTBot, ClaudeBot and Google-Extended, and references `https://agronom4u.com/sitemap-index.xml`.

## AI files

- `src/pages/llms.txt.ts` generates `/llms.txt` at build time.
- It links field crops, garden crops, calculators, rotation, blog and FAQ pages.
- Each field crop has 13 topic links generated from `FIELD_TOPICS`.

## URLs

Canonical URLs are built from `SITE.url` plus the Astro request pathname, or an explicit `canonicalPath` prop.

## Open Graph images

- Default OG image is `/og/default.png`.
- Pages can override with the `ogImage` prop.
- OG images are 1200 x 630 PNG files generated by `scripts/generate-og.mjs`.

## Configuration touchpoints

- Site URL and sitemap: `astro.config.mjs`.
- Page-level metadata defaults: `src/data/site.ts`.
